# Артефакты моделей

Каталог содержит готовые результаты обучения, поэтому сервис поднимается без шага обучения и все эндпоинты отвечают сразу.

| Файл | Что это |
|---|---|
| scoring_bundle.joblib | скоринг на синтетике, модель вместе с калибровкой и метриками |
| scoring_catboost.cbm | та же модель в формате CatBoost, по ней сервис проверяет готовность артефактов |
| scoring_meta.json | AUC, KS, PSI и распределение грейдов скоринга на синтетике |
| real_msme_bundle.joblib | скоринг на открытом датасете Kaggle MSME, модель и границы грейдов |
| real_msme_catboost.cbm | модель MSME в формате CatBoost |
| real_msme_meta.json | метрики модели MSME и границы грейдов |
| real_msme_resmlp_metrics.json | метрики референсной сети ResMLP для сравнения |
| lpr_bundle.joblib | модель склонности лица, принимающего решение |
| lpr_catboost.cbm | модель склонности в формате CatBoost |
| lpr_meta.json | метрики модели склонности |
| demo_profiles.json | девять демонстрационных заявок для страницы предпросмотра баннеров |
| demo_msme.json | пять реальных компаний из датасета для эндпоинтов /msme |

Три файла в репозиторий не входят, их пересобирает python train.py: датасет синтетики synthetic_dataset.csv, история взаимодействий lpr_interactions.csv и веса референсной сети real_msme_resmlp.pt. Метрики референса при этом остаются в real_msme_resmlp_metrics.json, поэтому GET /metrics показывает сравнение и без весов.

Модели и демо-профили детерминированы по seed, при повторном обучении файлы воспроизводятся.
